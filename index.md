# Literature Comb — surviving leads

Consolidated public ledger of surviving leads from the Literature Comb project — Swanson-style literature-based discovery, where "undiscovered public knowledge" (a connection between two live literatures that have never cited each other) is surfaced by combing old and cross-field sources against modern problems. Each row is a hypothesis worth one cheap check, not a finding. Found by automated literature sweep; not refereed; no claim here is medical, clinical, legal, or financial advice.
